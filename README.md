# Mole Calendar - Календарь родинок

Android-приложение для отслеживания родинок и напоминаний о необходимости их проверки.

## Функционал

- ✅ Добавление родинок с фотографиями
- ✅ Указание местоположения, размера, цвета и описания
- ✅ Фотографирование родинок через камеру
- ✅ Установка напоминаний о следующей проверке
- ✅ Просмотр истории изменений
- ✅ Уведомления о необходимости проверки
- ✅ Хранение данных в локальной базе данных

## Технологии

- **Язык**: Kotlin
- **Минимальная версия Android**: 7.0 (API 24)
- **Целевая версия Android**: 13 (API 33)
- **Архитектура**: MVVM с использованием:
  - Room Database для хранения данных
  - LiveData для реактивного обновления UI
  - ViewModel для управления состоянием
  - WorkManager для уведомлений
  - Glide для загрузки изображений
  - Material Design Components для UI

## Сборка APK

### Требования

- Android Studio Arctic Fox или новее
- JDK 11 или новее
- Android SDK с API level 33

### Инструкции по сборке

#### Способ 1: Используя Android Studio (рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Crypt0putin/mole-calendar.git
   cd mole-calendar
   ```

2. Откройте проект в Android Studio

3. Подождите, пока Android Studio скачает все зависимости

4. Выберите `Build > Build Bundle(s) / APK(s) > Build APK(s)`

5. APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`

#### Способ 2: Используя командную строку

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Crypt0putin/mole-calendar.git
   cd mole-calendar
   ```

2. Выполните сборку:
   ```bash
   ./gradlew assembleDebug
   ```

   Для Windows:
   ```bash
   gradlew.bat assembleDebug
   ```

3. APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`

#### Способ 3: Сборка Release версии (с подписью)

1. Создайте файл `keystore.properties` в корне проекта:
   ```properties
   storePassword=YOUR_STORE_PASSWORD
   keyPassword=YOUR_KEY_PASSWORD
   keyAlias=YOUR_KEY_ALIAS
   storeFile=YOUR_KEYSTORE_FILE_PATH
   ```

2. Выполните сборку:
   ```bash
   ./gradlew assembleRelease
   ```

3. APK будет создан в `app/build/outputs/apk/release/app-release.apk`

## Использование приложения

1. **Добавление родинки**:
   - Нажмите на кнопку "+" внизу экрана
   - Сфотографируйте родинку (опционально)
   - Заполните информацию: местоположение, описание, размер, цвет
   - Выберите дату следующей проверки
   - Включите напоминания при необходимости
   - Нажмите "Сохранить"

2. **Просмотр деталей**:
   - Нажмите на любую родинку в списке
   - Просмотрите всю информацию и фотографии
   - Используйте кнопку "Редактировать" для изменения
   - Используйте кнопку "Удалить" для удаления

3. **Уведомления**:
   - Приложение автоматически напомнит вам о необходимости проверки
   - Нажмите на уведомление, чтобы открыть детали родинки

## Разрешения

Приложение запрашивает следующие разрешения:

- **Камера** - для фотографирования родинок
- **Хранилище** - для сохранения фотографий
- **Уведомления** (Android 13+) - для отправки напоминаний

## Безопасность и конфиденциальность

- Все данные хранятся локально на вашем устройстве
- Никакие данные не отправляются на внешние серверы
- Фотографии сохраняются в защищенной папке приложения

## Структура проекта

```
app/src/main/
├── java/com/molecalendar/
│   ├── MainActivity.kt              # Главный экран со списком
│   ├── AddMoleActivity.kt           # Экран добавления родинки
│   ├── MoleDetailActivity.kt        # Экран деталей родинки
│   ├── Mole.kt                      # Модель данных
│   ├── MoleDao.kt                   # DAO для работы с БД
│   ├── MoleDatabase.kt              # Конфигурация Room DB
│   ├── MoleRepository.kt            # Репозиторий
│   ├── MoleViewModel.kt             # ViewModel
│   ├── MoleAdapter.kt               # Адаптер RecyclerView
│   ├── NotificationHelper.kt        # Помощник уведомлений
│   └── ReminderWorker.kt            # Worker для напоминаний
└── res/
    ├── layout/                      # XML layouts
    ├── values/                      # Строки, цвета, темы
    └── xml/                         # Конфигурационные файлы
```
